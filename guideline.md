# Project Guidelines

## Coding Style
1. Use camelCase for method names
2. Use snake_case for variable names
3. Use PascalCase for class names

## Laravel Specific
1. Use resource controllers for CRUD operations
2. All database interactions should go through Eloquent models
3. Use form requests for validation

## Testing
1. All features must have corresponding tests
2. Use factories for test data
3. Mock external services in unit tests
